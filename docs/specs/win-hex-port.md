# Windows повторяет Mac после hex-полировки — черновик спеки

Статус: идёт гриллинг. Решения заносятся сюда с датой.
Поручение Сергея, 06.11.2026: «отлично все работает на macOS - теперь надо сделать все так же на windows! сверяйся с тем как сделан hex и переноси на windows лучшие практики. тестируем на win машине в нашей сети tailscale».

## Что есть сейчас (06.11.2026)

- Windows `win/` 0.1.10 (последний тег win-v0.1.9): диктовка (облако + две локальные модели), история, HUD-плашка, трей, автозапуск, автообновление.
- Нет: онбординга, настроек как на Mac, выбора места плашки и новой волны, звуков ElevenLabs, тишины/буфера/коротких ошибок на плашке, Gemini и OpenAI, одной копии модели, встреч и саммари.
- Тестовая машина: zenbook (Windows 11 Pro, WIN-0EEOD28MBUQ, tailnet 100.88.29.3, вход через WSL `ssh zenbook`). В Windows нет Rust, Node и git; sezish не установлен.
- Образец поведения — код Mac `app/Sources/` (hex-polish, 0.1.24) и спека `docs/specs/hex-polish.md`.

## Решения

Раунд 1, 06.11.2026:
1. **Объём:** релиз 1 — диктовка со всей hex-полировкой Mac; релиз 2 — встречи (запись звонка, Я/Они, саммари, имя из саммари).
2. **Сборка:** ставим Rust, Visual Studio Build Tools, Node, git в Windows на zenbook; сборка, тесты и живая проверка там.
3. **Исполнитель:** Claude в этой сессии, последовательно, строго TDD и TLA+, как на Mac.
4. **Выпуск:** после живой проверки — всем через dl.sezi.sh/win (тег win-v0.1.x, подпись, latest.json).

Раунд 2, 06.11.2026:
5. **Вид:** экраны и карточки как на Mac (бренд: тёплый камень, красный акцент), но по-виндоусному: Segoe UI Variable, фон Mica, родная шапка окна Windows 11.
6. **Плашка:** по умолчанию внизу по центру над панелью задач; в настройках второй вариант — сверху по центру. Экран — тот, где активное окно.
7. **Поддержка:** только Windows 11.

Принято по умолчанию, без отдельного вопроса (обратимо):
- Онбординг: микрофон (проверка доступа, кнопка «Открыть параметры» → `ms-settings:privacy-microphone`) → движок (облако или на этом компьютере, две карточки моделей по языку, загрузка фоном) → готово (клавиша, автозапуск, «Живёт в трее», «Начать»). Специальных возможностей Windows не требует, шага «Accessibility» нет.
- Аналог Secure Input: вставка в окно, запущенное от администратора (UIPI), не проходит — плашка «текст в буфере — Ctrl+V» и строка в «Общих» с «Как исправить».
- Звуки — те же семь файлов ElevenLabs, что на Mac, громкость и выключатель как на Mac.
- Клавиша по умолчанию остаётся правый Ctrl.
- Язык интерфейса по системе (узбекский или русский), переключатель на экранах онбординга.

## План релиза 1 (диктовка), куски по порядку

Каждый кусок: красный коммит → зелёный коммит `win:`; сборка, тесты и живой снимок экрана на zenbook. Поведение и числа — из кода Mac 0.1.24.

0. **Сборка на zenbook.** Git, Rust (MSVC), VS Build Tools, tauri-cli; сборка 0.1.10 как есть, установка, снимки экрана «до».
1. **Ядро** (`sez-core`): тишина отбрасывается молча (−50 dBFS по самому громкому окну 30 мс, Mac `SilenceGate`), карта исходов → короткие ошибки плашки (Mac `HUDNotice`) и звуки (Mac `SoundEvent`).
2. **Звуки:** семь файлов Mac (`sound-<событие>`) в WAV, проигрыватель с громкостью 0…1 (по умолчанию 0,5) и выключателем; старый чайм удаляется.
3. **Плашка:** без тени, S-волна «Живее» с авто-уровнем и переключателем силы (Mac `SezishWaveView`), место «внизу над панелью задач» / «сверху», пилюля короткой ошибки (2 или 4 с, клик открывает «Общие»), режим без анимации по системной настройке Windows «Эффекты анимации».
4. **Вставка:** не прошла — текст остаётся в буфере, пилюля «Ctrl+V»; окно от администратора (UIPI) распознаётся заранее, строка в «Общих» с «Как исправить»; метка буфера для менеджеров истории (`ExcludeClipboardContentFromMonitorProcessing`).
5. **Движки:** OpenAI (`gpt-transcribe`, `gpt-4o-mini-transcribe`, свой ключ) и Gemini Live (SMART/VERBATIM, свой ключ), как на Mac.
6. **Локальная модель:** одна копия на всё приложение (Mac `LocalEngineSlot`, TLA+ `LocalEngine`), веса без перепаковки (`session.disable_prepacking=1`), выбор модели по языку.
7. **Настройки как на Mac:** боковая панель (Общие / Распознавание / История), одна карточка строк + «Дополнительно ▸», версия и «Проверить обновления» внизу; Segoe UI Variable, Mica.
8. **Онбординг:** микрофон → движок → готово (TLA+ по образцу `Onboarding.tla`, свои мутанты).
9. **История:** поиск, группы по дням, копирование, повтор неудачных, прослушать.
10. **Выпуск:** версия, тег win-v0.1.x, latest.json, живая проверка Сергея на zenbook.

Расхождения с Mac:

1. Gemini на Windows идёт одним запросом (`generateContent`, путь Mac для длинных повторов), а не Live-сокетом: текст приходит после отпускания клавиши, без потока.
2. Переход «капсулы → спиннер» на плашке — CSS-спиннер, а не морф.
3. Строки «окно администратора» в «Общих» нет: предупреждает только пилюля.
4. Ширина пилюли считается по числу символов.
5. Слот одной копии модели (`LocalEngineSlot`) не перенесён: встреч на Windows ещё нет, а диктовка держит одну копию и так.
6. Тест настроек пишет строку в настоящий журнал `%APPDATA%\sezish\sezish.log` той машины, где идут тесты.
