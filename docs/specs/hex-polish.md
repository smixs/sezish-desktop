## Что есть у hex (код прочитан, `anomalyco/hex@afb11de`, MIT, © 2026 Christopher Langton)

- **Стек другой.** hex — Rust со своим GPU-фреймворком Rune (wgsl). Перенос в sezish — это переписывание на SwiftUI/AppKit, а не копирование кода. Исключение — `native/permission_guide.m` (Objective-C, 616 строк): его можно перенести почти построчно.
- **Автомат онбординга** `src/desktop/onboarding.rs` (~1200 строк без тестов):
  - шаги `Welcome → Setup → TryIt → Done`;
  - состояния разрешения `Ready / NeedsRequest / NeedsSettings / NeedsRestart`;
  - статусы строки `Todo / Waiting / Stale / Denied / Restart / Downloading(p) / Failed`;
  - эффекты `RequestMicrophone / ShowGuide / ResetPermission / DownloadModel / AdvanceSoon / Relaunch / Finish`;
  - исходы пробы `Waiting / Listening / Transcribing / TooShort / NothingHeard / Landed / Failed`.

  Автомат чистый и под TLA+ ложится прямо.
- **«Still grey»** (`StalePermissionTracker`): человек ушёл в System Settings и вернулся, а доступа нет. Через 2 с ставится Stale; при окнах рядом — через 6 с. Тогда `tccutil reset Accessibility <bundle>` для своего и старых bundle ID и повторный запрос.
- **Подсказка рядом с System Settings** (`permission_guide.m`):
  - плитка с иконкой приложения перелетает из окна к System Settings (подъём 0,18 с, полёт 0,62 с, easeInOutCubic, размытие);
  - панель встаёт в правый нижний угол окна настроек с отступом 16 pt;
  - текст «↑ Drag Hex into the Accessibility list above»;
  - открывается `x-apple.systempreferences:com.apple.settings.PrivacySecurity.extension?Privacy_Accessibility`;
  - в macOS 27 список называется «Device Control and Data Access».
- **Экраны** (эталонные снимки `tests/golden/*.png`):
  1. «Setting up Hex». Строка «Downloading [English ▾] speech model» с выбором языка прямо в фразе, пилюля с процентом.
  2. «Five times faster / Typed with two typos. Spoken without any.» Карточка сообщения, клавиатура, сравнение «Typing too long | Hex fast», кнопка «Continue →».
  3. «Let Hex hear you and type for you / macOS asks once…». Карточка из двух строк: Microphone «Hears you only while you hold the shortcut» и Accessibility «Notices the shortcut and pastes your words in any app», кнопки Allow → «✓ Allowed». Пилюля загрузки уезжает наверх.
  4. Stale: «An older Hex entry can keep this off» + «Still grey? Fix it».
  5. «Clear your messages». Hold [Alt][Space], карточки-уведомления, настоящая плашка диктовки внизу; Skip и Done.
  6. «Hex is ready». Hold [Alt][Space] anywhere, then talk; «Lives quietly in your menu bar»; кнопки Try again и Start using Hex.
- **Визуальный язык hex:**
  - нейтральный серо-чёрный, светлая и тёмная темы;
  - крупные полужирные заголовки по центру;
  - карточки с тонкой рамкой;
  - клавиши нарисованы кнопочками (keycaps);
  - одна тёмная главная кнопка;
  - тишина вокруг.
- **Настройки:**
  - боковая панель General / Output / History / Meetings / Labs;
  - внизу Quit, версия и «Check for updates»;
  - одна карточка строк с иконками: Shortcut (keycaps), Shortcut mode, Speech model, Vocabulary, Microphone (уровень + устройство), Launch at login;
  - редкое спрятано под «Advanced ▸».
- **Плашка Dot scope** (`src/rune_hud/dot_scope.rs`): поле точек, которое зажигают две сплетённые осциллограммы голоса; симуляция на 240 Гц. Варианты места: Below / Menu bar / Notch. Обработка — Flow / Pulse / Sweep. Есть Auto level.
- **Звуки:**
  - 8 наборов в `resources/audio/sounds/*/{start,stop,done,cancel,error,success}.wav`;
  - отдельные звуки онбординга (`almost_ready`, `hexagon`, `key_*`);
  - сторонней лицензии в NOTICES нет, значит MIT репо.
- **Иконки:** Lucide (ISC/MIT), шрифт интерфейса похож на Inter.

## Что есть у sezish

  - радиусы 16 / 12 / 10 / 8.
- Плашка: S-волна + кольцо (`SezishWaveView`, `MetalRimView`).
- Настройки — `NavigationSplitView` 520–620 × 440–520, 7 вкладок.

## Противоречия с правилами репо

- ADR-0003 и AGENTS.md: «поведение и константы — только из кода macOS, никогда из OSS-аналогов». Поручение Сергея прямо велит брать из hex, значит нужна новая ADR-исключение.
- AGENTS.md: «Closed-source». Код и звуки hex под MIT можно брать, если сохранить копирайт и текст лицензии в NOTICES.

## Решения

Раунд 1, 05.11.2026, ответы Сергея:
1. **Вид:** структура и движение hex, цвета, акцент и тени бренда sezish.
2. **Выпуск:** всё одним релизом — онбординг, настройки, плашка, звуки.

Раунд 2а, 05.11.2026:
5. **Шаги:** разрешения → готово, без языка и демо. Локальная модель спрашивается отдельным шагом «облако или локально» (ответ 6), поэтому шагов три: разрешения → модель → готово. Порядок уточняется.
6. **Модель:** отдельный шаг с выбором «облако или локально» и объяснением.
7. **Обновившиеся пользователи:** онбординг открывается, только если чего-то не хватает (разрешения или движок). Остальные его не видят.
8. **«Всё ещё серое? Исправить»:** делаем, как в hex. Stale через 2 с после возврата из System Settings или через 6 с при окнах рядом; `tccutil reset Accessibility com.smixs.sezish`, затем повторный запрос.

Раунд 2б, 05.11.2026:

Раунд 8, 05.11.2026:
37. **Звуки:** первые варианты всех семи (старт, стоп, готово, отмена, ошибка, старт и стоп встречи). Сгенерированы в ElevenLabs; начало обрезано по тишине, громкость выровнена (loudnorm I=-20, TP=-3), в приложении лежат как `Resources/sound-<событие>.caf`, 16 бит моно. Старые синтезированные чаймы и их генератор удалены. Ошибка звучит и при неудачной вставке, пока её не заменит п. «вставка не прошла → буфер с подсказкой». Громкость — ползунок в строке «Звуки», по умолчанию 50 %, слышна при отпускании. Windows-версия пока на старом чайме.
38. **Переименование встречи:** меняется только название в файле и в списке, имена файлов остаются. Так ссылки на аудио и саммари в вольте не рвутся.

Принято при реализации правок «не работает», 05.11.2026 (по умолчанию, обратимо):
- Запись без речи: порог hex −50 dBFS по самому громкому окну 30 мс без постоянной составляющей. Детектор речи hex (Silero, отдельная загрузка) не переносим. Старт-звук из динамиков ноутбука может поднять тихую запись выше порога — тогда она идёт в распознавание, как раньше.
- Плашка вместо уведомлений: «текст в буфере — ⌘V» и «не расслышал» по 2 с; «микрофон не записал» и «модель не скачана» по 4 с, клик открывает «Общие». Уведомления этих четырёх случаев удалены.
- Метка буфера — только `org.nspasteboard.AutoGeneratedType`: текст остаётся в буфере (ADR-0005), поэтому Transient не ставим. Менеджеры буфера, которые чтут метку, не пишут диктовки в свою историю.
- Secure Input опрашивается раз в секунду; владельца называет IORegistry (`IOConsoleUsers`). Метка — точка в углу значка в строке меню.
- Место плашки: «Внизу» (по умолчанию), «Под строкой меню» (10 pt под ней), «У выреза» (6 pt под вырезом; без выреза — под строкой меню). Сверху плашка въезжает сверху вниз. Reduce Motion: остаётся только затухание, без сдвига и растяжения в пилюлю.
- Концовки hex (Done и Failed) у нас — звук «готово» или «ошибка» плюс пилюля ошибки. Отдельную анимацию «готово» на плашке не делали.
