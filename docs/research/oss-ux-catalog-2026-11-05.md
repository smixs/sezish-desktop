# UX-каталог мелочей у конкурентов sezish — 05.11.2026

🟡 Онбординга у нас нет, а в нём сидит главная жалоба пользователей («не работает», потому что разрешения не включены). Ниже 190 мелочей из 10 проектов: у каждой указано, у кого она есть и как выглядит у нас.

## Как собрано

Всё прочитано вручную, без пересказа моделью:
- hex: 12 файлов `docs/features/*.md` (~620 КБ) с деревьями сценариев, где каждая ветка — состояние экрана.
- Handy: все 664 строки интерфейса из `locales/en/translation.json`.
- opentypeless: ~610 строк `en.json`.
- natter, Talkify, Detto: строки интерфейса, вытащенные из Swift-кода.
- meetily: компоненты онбординга и встреч.
- quill, Detto, Talkify: README с описанием поведения.
- У sezish сверял код (`app/Sources/SezishApp`, панели настроек, `AppState`). Пометка ❓ значит, что код не досмотрел.

Обозначения: ✅ у нас есть · 🟨 частично или хуже · ❌ нет · ★ брать в первую очередь.

## 12. Рисование на экране: hex Annotate против нашей ADR-0019

Аналог у конкурентов есть: hex встроил движок Scrawl в функцию Annotate. Назначение разное:
- **hex** снимает видео с голосом для агента;
- **sezish** — это диктовка с картинками, текст главный.

| | hex Annotate | sezish (спека v3) |
|---|---|---|
| Запуск | Отдельная клавиша ⌥⇧S, тап = старт/стоп | Внутри обычной диктовки |
| Рисование | Удержание клавиши или Shift, без клика; перо на плашке | ⇧ + тянуть |
| Чернила | Держатся 650 мс, гаснут 650 мс; лазер с хвостом 420 мс; отмены штриха нет | Метка [n] на каждый штрих |
| Результат | Видео, ключевые кадры по словам «смотри», «здесь», «это», контактный лист + summary.md | Снимок на штрих, пропорциональные метки в тексте |
| Плашка | `● 0:07 │ ✎ │ ■ ✕`; ✕ спрашивает «Discard?» и через 4 с возвращается к записи | Плашка диктовки |
| После | «Copied» → Paste (лист + текст), Inspect, Send to… с кольцом Undo 5 с | Вставка картинок и текста |
| Разрешение | Запись экрана спрашивается при первом снимке, в плашке подсказка «Hex needs Screen Recording · Allow» | ❓ |
| Без разрешения | Уходит голос и метки с пометкой «No screen: Screen Recording is off» | ❓ |
| Esc | Останавливает рисование, запись продолжается | ❓ |
| Своя плашка в кадре | Исключена из записи | ❓ |
| Терминал не берёт картинку | Вставляется путь к контактному листу | ❓ |

Что взять в нашу спеку:
- тайминги чернил;
- исключить свои окна из снимка;
- спрашивать запись экрана при первом штрихе с подсказкой в плашке;
- без разрешения отдавать только текст с пометкой;
- Esc гасит перо, диктовку оставляет;
- путь вместо картинки для терминала;
- контактный лист: один снимок с пронумерованными кадрами вместо пачки картинок.

## 13. Что брать первым

**Пакет «Онбординг»** напрямую закрывает жалобу «не работает». В него входят пункты:
- 1, 2, 4, 7, 8 — окно первого запуска, язык, загрузка модели в фоне, разбор сбоя загрузки, облако, пока модель качается;
- 9, 11, 12 — демо и разрешения с объяснением «зачем»;
- 14–17 — автопереход, подсказка рядом с System Settings, «Open System Settings» после отказа, «Still grey? Fix it»;
- 19 — возврат на сохранённый шаг;
- 23, 24 — проба с разбором неудачи;
- 28, 29 — финал «Всё готово» и авто-перезапуск слушателя.

Состояние онбординга с порядком событий — разрешения, загрузка, перезапуск, возврат на шаг — требует модели TLA+ по правилам репо.

**Дешёвые правки, которые снимают «не работает» уже сейчас:**
- 59, 60 — Secure Input и диагностика клавиатуры;
- 82 — короткие ошибки на плашке;
- 88 — метки буфера;
- 89 — текст в буфер с объяснением при отказе вставки;
- 162 — точный путь к настройке микрофона;
- 164 — закрытая крышка;
- 168 — молча отбрасывать тишину.

**Встречи:** подавление эха (161) уже выбрано следующей задачей. За ним по ценности идут экран встреч (142–143), «Скопировать новое» (135) и календарь (132).
